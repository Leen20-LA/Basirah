# User Flow

## الهدف

يوضح هذا الملف رحلة المستخدم داخل بصيرة منذ لحظة فتح التطبيق وحتى انتهاء الجلسة، مع التركيز على كيفية انتقاله بين المراحل المختلفة لتحقيق تجربة بسيطة، واضحة، وخالية من التشتت.

يعتمد هذا التدفق على المبادئ الأساسية للمشروع، وأبرزها:

- نفهم قبل أن نقترح.
- الوضوح يسبق التنفيذ.
- المستخدم هو صاحب القرار.
- تقليل الحمل الذهني قدر الإمكان.

> ملاحظة: يصف هذا الملف منطق انتقال المستخدم داخل التطبيق، ولا يحدد تصميم الواجهات أو شكلها.

---

## التدفق الرئيسي (Main Flow)

```
فتح التطبيق
      │
      ▼
تظهر مساحة تفريغ بسيطة
      │
      ▼
يبدأ المستخدم بكتابة أفكاره بحرية
      │
      ▼
يتم الحفظ تلقائيًا أثناء الكتابة
      │
      ▼
يضغط المستخدم "تم"
      │
      ▼
يبدأ بصيرة التحليل
(مع رسائل توضح ما يجري)
      │
      ▼
هل توجد نقطة مؤثرة غير واضحة؟
      │
 ┌────┴────┐
 │         │
لا        نعم
 │         │
 ▼         ▼
عرض      يطلب توضيحًا
النتيجة      │
             ├──────────────┐
             │              │
        توضيح المستخدم    تجاهل
             │              │
             └──────┬───────┘
                    ▼
             استكمال التحليل
                    ▼
               عرض النتيجة
                    │
                    ▼
      يستطيع تعديل النص وإعادة التحليل
                    │
                    ▼
              حفظ الجلسة تلقائيًا
                    │
                    ▼
                 نهاية الجلسة
```
