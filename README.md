# Basirah

> Turning mental clutter into clear, actionable steps.

## About

Basirah is a personal project that aims to help people transform mental clutter into clarity.

Instead of acting as a traditional to-do list or a conversational AI, Basirah focuses on understanding unstructured thoughts, identifying what truly matters, and helping users build a clear path toward action.

The project is currently in the research and planning phase.

## Current Stage

- ✅ Vision definition
- 🔄 User research
- 🔄 Product planning
- ⏳ Prototype design
- ⏳ Development
